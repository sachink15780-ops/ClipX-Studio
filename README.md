# ClipX Studio

ClipX Studio is a browser-based video editor built as a single HTML app.

## Features
- Multiple video clips on a timeline; drag clips to reorder and trim clip edges
- Split at playhead, delete clips, timeline zoom
- Dissolve and dip-to-black transitions
- Fade in/out, zoom/pan keyframes (Ken Burns)
- Speed controls, text/title overlays, color clips
- MP4/H.264 + AAC export when supported, GIF export, WebM fallback
- Project autosave in browser storage
- Mobile-friendly browser UI

## Run / Deploy
Open the GitHub Pages site when enabled. To enable it: repository **Settings → Pages → Build and deployment → Source → GitHub Actions**.
